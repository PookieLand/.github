================================================================================
                         DATA FLOW & RELATIONSHIPS
================================================================================

1. CONTAINER MANAGEMENT:
   K8s Master + Workers ───pulls images───► ECR

2. LOAD BALANCING:
   External Traffic ───► NLB ───routes to───► K8s Worker Nodes

3. SECRETS:
   K8s Nodes ───reads───► AWS Secrets Manager

4. MONITORING (Cross-region):
   Prometheus (SG) ───scrapes metrics───► K8s Master + Workers (IN)
   
5. LOGGING (Cross-region):
   K8s Master + Workers (IN) ───ships logs───► OpenSearch (SG)

6. VISUALIZATION:
   Grafana ───queries───► Prometheus + OpenSearch

7. ALERTING:
   Prometheus ───sends alerts───► Alertmanager

================================================================================
                         SECURITY & ACCESS
================================================================================

HRMS Cluster:
  - Master Security Group: API server (6443), SSH (22)
  - Worker Security Group: NodePort range (30000-32767), SSH (22)
  - All nodes have Elastic IPs for stable external access

Monitoring Server:
  - Public Access: SSH (22), Grafana (3000), OpenSearch (9200, 5601)
  - Internal Only: Prometheus (9090), Node Exporter (9100), Alertmanager (9093)
